This project is a full-stack online learning platform inspired by Udemy, built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

It provides a seamless experience for both learners and instructors, allowing users to discover courses, enroll, and learn through structured video content.

Features:
- User authentication and authorization (JWT-based)
- Browse, search, and filter courses
- Course enrollment and management
- Video streaming for lessons
- Instructor dashboard to create and manage courses
- Progress tracking system
- Responsive UI for all devices

Tech Stack:
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JSON Web Tokens (JWT)

This project demonstrates the implementation of a scalable and modern e-learning platform with a focus on performance, usability, and clean architecture.
